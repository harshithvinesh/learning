    Connecting Your Real Backend Server
    
          
    This frontend application is built from the ground up with a decoupled service-oriented architecture. All data access, code submissions, and state persistence flow through js/api-client.js.

    Currently, the app uses Local Browser Mode (in-memory execution with localStorage persistence). When you are ready to write server-side code (Express, FastAPI, Gin, etc.), simply point the app to your backend URL.

    🚀 Ready-To-Run Node.js / Express Backend (server.js)
    
          
    Copy this minimal starter into a folder, run npm init -y && npm install express cors, and start it with node server.js on port 4000:
    
          
    const express = require('express');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json());

// In-memory or database progress store
let userProgress = {
  solvedProblemIds: [],
  submissionsCount: 0,
  streakDays: 1
};

// 1. Health check
app.get('/api/health', (req, res) => {
  res.json({ status: 'ok', serverTime: new Date().toISOString() });
});

// 2. User Progress
app.get('/api/user/progress', (req, res) => {
  res.json(userProgress);
});

app.put('/api/user/progress', (req, res) => {
  userProgress = { ...userProgress, ...req.body };
  res.json(userProgress);
});

const PORT = process.env.PORT || 4000;
app.listen(PORT, () => {
  console.log(`Backend Dev Arena server running at http://localhost:${PORT}`);
});
    
        
    

        
        
    
          
    🐍 Python FastAPI Alternative (main.py)
    
          
    If you prefer Python, install pip install fastapi uvicorn and run with uvicorn main:app --port 4000 --reload:
    
          
    from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
from typing import List
import datetime

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

progress_db = {
    "solvedProblemIds": [],
    "submissionsCount": 0,
    "streakDays": 1
}

@app.get("/api/health")
def health():
    return {"status": "ok", "timestamp": datetime.datetime.utcnow().isoformat()}

@app.get("/api/user/progress")
def get_progress():
    return progress_db

@app.put("/api/user/progress")
def update_progress(data: dict):
    progress_db.update(data)
    return progress_db
